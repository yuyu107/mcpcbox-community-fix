# MCPCBox Community Fix · Native Adapter v18（测试版）

本次更新集中恢复官方版本下载，并整理下载中心、共享缓存和页面交互。v18 进一步修正重试回调、文件收尾以及任务结束状态同步问题。

**建议以 Pre-release 发布，标签使用 `native-adapter-v18`。** 这是本轮原生下载适配的测试编号，现有 v6.5 稳定版继续保留。

## 下载与使用

下载附件 `MCPCBox_NativeAdapter_v18.zip`，解压后：

1. 完全退出盒子，备份原 `MCPCBox.exe`。
2. 将包内 `MCPCBox.exe` 覆盖到原程序位置，保留现有 DLL、游戏文件和缓存。
3. 重新打开盒子，在游戏下载页选择版本，使用下载中心查看整体任务。

这是替换主程序的更新包，需配合已有盒子安装文件使用。包内含 `Source-v18.zip`、变更说明与本地验证结果。

本次同步补齐了源码包遗漏的前端测试脚本，主程序二进制与此前 v18 相同。请使用本次整理后的附件。

## 本轮新增功能

- **动态官方目录**：版本清单、元数据和文件地址从 Mojang 官方数据获取。
- **统一原生下载**：游戏文件继续调用盒子的 `CDownloadManager / taskmodulehttp.dll`；完整版本以一条任务显示整体字节进度。
- **共享缓存**：按官方 SHA-1 和大小校验，重试、重装及不同版本可复用相同内容；安装文件与缓存采用独立副本。
- **已下载多选**：支持仅删除记录并保留文件；普通资源可删除文件及记录。卸载已安装版本仍使用游戏管理。
- **页面整理**：操作结果使用独立提示框，说明默认折叠，下载按钮显示准备/下载状态；完成、失败、取消后的提示均可关闭。
- **首次简体中文**：新安装没有 `options.txt` 时初始化中文，区分旧版 `zh_CN` 和新版 `zh_cn`；已有玩家设置保留。

## v18 稳定性修正

- 修正重试复用同一路径时，旧任务迟到回调可能错误匹配新任务的问题。
- 等待原任务从管理器实际活动表退出后，再进行后续校验、发布或重试，避免重叠处理同一临时文件。
- 文件暂时被占用时增加有上限的等待；不放宽哈希和大小校验。
- 先同步下载中心，再显示网页任务结束；失败任务不再留在“下载中”计数内。
- 增加缓存、安装阶段的文件名与错误日志，便于继续定位失败原因。

## 目录与缓存说明

目录跟随盒子配置。若下载根目录为 `D:\MCBox\download`：

| 用途 | 位置 |
| --- | --- |
| 共享下载缓存 | `resources\official\objects` |
| 官方元数据缓存 | `resources\official\metadata` |
| 每版本缓存索引 | `resources\official\versions\<版本号>` |
| 已安装游戏 | `game\<版本号>\.minecraft` |

缓存主要减少重复传输，会额外占用磁盘并增加校验、复制工作，不保证首次安装更快。共享缓存暂不提供按单个版本回收；整体下载汇总记录目前只在当前进程内保留。

## 测试范围与已知问题

- 已通过本地前端状态回归、真实主机临时文件/SHA-1 测试，以及原入口、重定位、任务回调、下载中心投影和版本登记等机器码模拟回归。
- 测试使用 Windows/原组件 API 替身；真实 Windows 下载稳定性、内嵌 IE、断点续传和首次启动仍需实测，尚不能确认所有下载失败原因已解决。
- 能下载某个版本不代表旧启动器一定能启动该版本；仍受启动参数、Java、操作系统、显卡和游戏自身要求限制。
- 新页面的本机接口内嵌在 EXE 中，监听 `127.0.0.1:19481`，不需要外置插件；此前 v6.5 的“无需本地 HTTP 服务”描述不适用于这条新链路。
- 此前 360 告警尚未解决，未经过安全厂商复核；不要把本地回归通过理解为已经通过安全软件验收。

如果仍下载失败，请附上 EXE 同目录 `MCPCBox-native-download.log` 的末尾，包含 `Native retry`、`Cache/install failure`、`Version` 汇总及当时下载的版本号。
