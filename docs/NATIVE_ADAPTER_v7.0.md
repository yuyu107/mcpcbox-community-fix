# MCPCBox Community Fix v7.0 原生下载适配

公开版本号为 v7.0，项目恢复维护，对比基准为上一公开版本 v6.5；本页及源码路径中的 v19 是当前发布包的内部开发编号。发布说明请使用 [RELEASE_v7.0.md](RELEASE_v7.0.md)。

本轮开发在旧 MCPCBox 内恢复动态官方版本目录，并将多文件游戏安装接入原下载模块。源码位于 `src/native-v19/`，它使用此前 v4 单列表精确基底编译合并，与 v6.5 的字符串补丁流程分开维护。

## 下载与目录

- 版本清单、版本 JSON、依赖与资源索引读取 Mojang 官方数据，游戏文件从官方地址获取。
- 游戏文件的传输由 `CDownloadManager / taskmodulehttp.dll` 完成，下载中心按版本显示一条整体任务，进度按总字节数汇总。
- EXE 内嵌页面和本机接口监听 `127.0.0.1:19481`，使用随机令牌及来源检查；不需要额外插件、独立下载器或另外启动服务。
- 下载根目录读取盒子设置。若配置为 `D:\MCBox\download`，共享缓存位于 `resources\official`，安装位于 `game\<版本号>\.minecraft`。
- 缓存按官方 SHA-1 与大小校验，跨重试、重装及不同版本复用相同内容。安装文件使用独立副本，增加磁盘占用；主要减少重复下载，不承诺首次下载更快。

## 下载中心与游戏管理

已下载页支持多选、仅删除记录和打开目录。普通资源的文件删除限定在当前配置的 `resources` 目录中；整体版本任务可打开缓存索引目录、清理记录。卸载已安装版本请使用游戏管理，避免清历史时误删存档或安装目录。

共享缓存暂不支持按单个版本回收；已安装文件与缓存独立。缓存文件可跨重启复用；成功完成的整体任务记录也会保存并恢复，删除与清空结果同步保存。记录文件：`%APPDATA%\duowan\mcpcbox\community-fix\completed-history-v1.json`。

恢复保留记录编号、名称、缓存目录和 64 位大小；新任务编号避开已恢复的记录。不扫描游戏目录或缓存来重建已清理条目。此前旧进程已丢失的汇总记录无法自动找回。

## 页面与语言

已下载页的操作结果放入独立提示框；结束后可关闭，后台列表刷新不重新弹出。下载页默认收起说明、并发配置和单文件测试。按钮随任务显示准备中、下载中或等待当前任务，结束提示支持关闭。

成功安装且游戏目录不存在 `options.txt` 时初始化简体中文，按官方语言资源区分 `zh_CN` 和 `zh_cn`。已有设置不修改；这不是面向全部手动导入版本的启动钩子。

## 下载流程与记录修正

- 新增完成记录持久化，支持后台启动恢复、保存失败重试与损坏文件保留。
- 旧任务迟到回调按原生任务 ID 匹配，避免同路径重试串到新请求。
- 区分原生成功回调和管理器内部收尾；重试前等待旧任务退出，避免同时写同一临时文件。
- 文件共享、锁和访问冲突可短暂等待；保留完整哈希校验及错误上限。
- 先结束整体任务并同步通知下载中心，再公布网页结束状态。失败任务不再占用活动下载计数，也不会伪装成成功记录。

## 构建与验证

见 [BUILDING.md](BUILDING.md)、[源码说明](../src/native-v19/README.md) 和 [验证结果](validation/v7.0/)。校验值对应当前发布的 v7.0 附件；其中 validation.json 的发布标记是构建时记录，不是仓库当前同步状态。

本地已验证页面状态、官方安装计划、缓存与文件操作策略，以及原生适配入口、重定位、任务回调、下载中心投影和版本登记的模拟行为。Windows 与原组件 API 在测试中使用替身，不能由此认定实际网络失败率或 Windows UI 已通过验证。

真实 Windows 下载稳定性、内嵌 IE 排版、断点续传和各游戏版本启动仍待实测。旧启动器能获取某个官方版本，不等于它的参数处理、Java、系统或显卡一定支持该版本。此前 360 告警尚未解决，未经过安全厂商复核。

若下载仍失败，请保留 EXE 同目录下 `MCPCBox-native-download.log` 的末尾，尤其是 `Native retry`、`Cache/install failure` 和 `Version` 汇总。
