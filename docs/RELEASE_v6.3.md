# MCPCBox Community Fix v6.3

基于旧版多玩我的世界盒子 PC 版的社区兼容修复。

## 本版主要更新

- 恢复“游戏直播”页面。
- 旧版盒子内嵌浏览器可播放当前虎牙《我的世界》直播。
- HLS/HS 优先，多 CDN 自动切换与缓冲恢复。
- 修复顶部“多玩贴吧”按钮，改为“多玩我的世界盒子吧”。
- 更新“关于盒子”页面为“2026 社区兼容修复版”。
- 保留此前 Java 下载、Minecraft 版本 JSON、“精彩视频”和本地皮肤管理等修复。

## Release 建议附件

- `MCPCBox_Community_Fix_v6.3.exe`
- `MCPCBox_Community_Fix_v6.3.zip`

## 使用方法

1. 完全退出多玩我的世界盒子。
2. 建议备份安装目录中的原 `MCPCBox.exe`。
3. 下载 Release 中的修复版 `MCPCBox.exe`，覆盖原文件。
4. 重新启动盒子。
